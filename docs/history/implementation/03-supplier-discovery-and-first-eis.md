не записывает карточки как подтверждённое КП. Узкий каталог не выдаётся за
широкий поиск по площадкам. Для следующих срезов нужны проверенные публичные
API или разрешённые каналы конкретных многокатегорийных площадок; их текущий
статус — не подключены. ГИСП с текущего хоста ответил HTTP 403.

Evidence: live read-only запрос категории ServerMall получил HTML 570 557 байт
и 8 совпадений `HPE ProLiant Gen12` 2026-09-21. Связанные unit и API тесты
покрывают DOCX → exact approval → оба источника, provenance и ошибку каталога.
