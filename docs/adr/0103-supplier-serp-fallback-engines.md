# ADR 0103: дополнительные поисковики для поиска производителя

Дата: 2026-10-06. Статус: withdrawn по запросу пользователя, 2026-10-06. На production не устанавливался.

## Отмена

Brave Search, DuckDuckGo и Mojeek удалены из активного поиска: live organic-success
не подтверждён. Runtime снова использует только Bing, Яндекс, Google, policy v1,
20 секунд на источник и ZIP до 8 МиБ. Парсеры и fixtures отозванных адаптеров удалены.
Имена engines и wire v2 остаются исключительно для чтения неизменяемого исторического
report/evidence; request allowlist запрещает новые обращения к отозванным источникам.
Миграция012 сохраняется для совместимости уже записанных локальных v2 данных.

## Историческое решение

Версия `eis-position-supplier-serp-v2` наблюдает один публичный запрос в порядке
Bing → Brave Search → DuckDuckGo HTML → Mojeek → Яндекс → Google. Это один
ограниченный последовательный пакет альтернативных источников: максимум шесть
переходов к выдаче, десять ссылок на источник, без переходов к найденным сайтам.
Браузер Chromium; дополнительные браузерные движки не добавляются.

Общий браузерный бюджет 75 секунд, запуск 10 секунд, источник 10 секунд;
subprocess остаётся ограничен 90 секундами. Исчерпание времени явно фиксируется
для оставшихся источников. CAPTCHA, 403/429 и неизвестная структура не становятся
пустой выдачей; обход защит отсутствует. Навигация ограничена точными HTTPS URL
с запросом и фиксированными доменами ресурсов. Commercial facts остаются UNKNOWN.

## Совместимость и evidence

Неизменяемые v1 отчёты сохраняют три источника и исходный JSON/SHA. Read сначала
ищет v2, затем возвращает v1 с нулём source I/O. Prepare использует только v2
cache; недавняя v1 попытка блокирует новый I/O на общие 15 минут, включая смешанное
развёртывание. BLOCKED/RATE_LIMITED cooldown и tenant quotas общие для версий.
Exact parent run ID сохраняется для открытия страницы и карточки.

Версия связана с точным порядком источников. DOM лимит остаётся 2 МиБ на источник,
ZIP evidence v2 ограничен 13 МиБ; v1 сохраняет 8 МиБ. Суточная квота 64 МиБ
резервирует новый максимальный bundle. Миграция `20261006_12` расширяет CHECK
constraints SERP и выбранной страницы, не изменяя историю, RLS и audit.

## Подтверждённые ограничения

Живая проверка текущей сети обнаружила Brave 429/CAPTCHA, DuckDuckGo 202/challenge
и Mojeek 403/automated queries. Успешная органическая выдача новых источников
не подтверждена. Synthetic parser/wire fixtures проверяют контракт и защиту от
ложных результатов; они не являются доказательством live availability.
Результаты проверок и границы выпуска — в
[контракте SERP](../suppliers/105-eis-position-supplier-serp.md).
