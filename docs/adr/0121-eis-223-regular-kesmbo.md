# ADR 0121: регулярные региональные окна KESMBO

Дата: 2026-10-26. Владелец root. Статус: PASS_BOUNDED_INSTALLED.
[Контракт V52](../eis/ingestion/140-eis-223-regular-kesmbo.md).

## Контекст

Адресный `purchaseNoticeKESMBO` уже разбирается и хранится. Регулярный запрос
по региону/дню, список семейств планировщика и основной региональный intake
его исключали. Retained официальный BY_REGION ответ UID
`5036a61f-1db5-40ec-8f02-5b346316b062` содержит полный архив этого семейства.
Его координаты привязаны к сохранённому операторскому selection manifest;
ответ сервера не содержит независимого echo региона/дня. Публикация и ИНН
не служат заменой координат запроса.

## Решение

Регулярный список включает четыре семейства извещений и прежние два семейства
отмен. Для нового регионального KESMBO требуется ephemeral frozen binding:
исходный ключ выбора, разобранные initial/prepared ответы. Перед импортом
проверяются исходный ключ, SHA ответов, BY_REGION, UID и полный набор URL.
Binding любого семейства проверяется повторно; ретег BY_NUMBER не допускается.
Старый явный BY_NUMBER и legacy ready старых трёх семейств сохраняют контракт.
Это защита доверенного workflow от переименования, а не подпись произвольно
сконструированного DTO. ZIP/XML SHA и source provenance сохраняются отдельно.

При распознанном точном старом наборе пяти семейств создаётся новая волна
шести семейств с теми же замороженными двумя датами и catalog SHA. Старые
targets, ordinals и attempts не изменяются; последние результаты по ключу
используются повторно. Подсчёта строк недостаточно: сравниваются полные множества
ключей, уникальность и pinned catalog. Частичный или неоднозначный scope
блокирует переход. Tenant advisory lock сериализует создание; при равной дате
и времени expanded wave имеет приоритет перед UUID старой волны.

Четыре CHECK расширяются миграцией `20261026_03`: source windows, sync attempts,
regional targets и wave bounds. Максимум 99 регионов × 2 дня × 6 семейств =1188;
для принятого каталога 90 регионов —1080 вместо900. Downgrade запрещён уже
при новых planned targets, даже до загрузки ZIP, а также при новых windows,
attempts или wave count>990. API/загрузчики и WEB DTO/labels должны быть
совместимы до создания таких данных; forward barrier устанавливается раньше.

## Последствия

Регулярная загрузка больше не пропускает это поддержанное семейство. Полнота
ЕИС остаётся UNKNOWN: новые 180 координат ещё требуют обработки, другие
семейства и исторические диапазоны не объявляются покрытыми. Наивный срок
остаётся UNKNOWN; семейство МСП не подтверждает допуск поставщика.

Бюджет54min/hour, atomic turn180s, batch32/60, защищённые полосы, source/import
leases, pacing, cooldown, TLS/robots, SQL/resource/tenant guards и cron прежние.
Истёкший V38 sweep не возобновляется. Ранее consumed адресные payload не повторяются.

## Альтернативы

Переписывание старых targets уничтожает принятую границу наблюдения. Переход
только по счётчику может принять неполный набор. Ретег BY_NUMBER не доказывает
BY_REGION. Новая волна с текущими вместо frozen дат теряет исходные пробелы.
