# ADR0081 — NO_DATA и публичный канал: сравнивать scope явно

Дата/effective2026-10-05. Статус: принято и установлено14:01:13UTC. Owner root.

## Контекст

Повтор NO_DATA в том же SOAP не является независимым подтверждением. Публичные
карточки ЕИС доступны через другой интерфейс, однако publication-day/allstages/
national scope не равен region/type/exactDate-offset/versions SOAP scope.

## Решение

Сначала verify retained raw + latest tenant journal; затем одна публичная50card
navigation under global import lease/shared cooldown. Проверять echoed date/law/
stage/page/search controls и visible dates/official URLs, сохранять rendered DOM
и typed proof, сравнивать <=50numbers с tenant indexed versions в отдельном PGRO.
Source absence/coverage/independent corroboration UNKNOWN всегда. Empty неPASS;
notindexed — кандидат адресной загрузки, не доказанный пропуск SOAP или выгодность.

Хранение DOM<=8MiB/depth64/nodes100000, tenant store<=32MiB/8immutable files, private
capture lock/permissions/reflection rejection. <=7days/30sSQL/1MiBJSON proof, noDBwrites.
Blocked/changed/cooldown/quota return typed UNKNOWN with known artifact/navigation
metadata; no guessed network counts. Runtime source/checkpoints/cron не меняются.
