# ADR0092: восстановление связи по scope и ID

Дата: 2026-10-06. Статус: принято и выпущено в S222; evidence в docs104.

## Контекст

S221 сохраняет проверенную связь, но exact-request read требует повторить
выбранные диапазоны. После перезагрузки они отсутствуют в состоянии формы.
Это мешает продолжать работу с исходной спецификацией.

## Решение

Добавить source0 bounded metadata list и detail по canonical UUID. Scope
связывает exact позицию и document UID/SHA/revision. Все source guards действуют
при list/detail, report реконструируется из источника. Cursor должен обозначать
существующую связь в этом же scope; pagination не скрывает ограниченность списка.
UI требует явного выбора; автоматическое принятие последней связи запрещено.

## Последствия

Контекст можно открыть без повторного выделения текста. Сохранение S221,
схема, approvals, completeness gates и source budgets не меняются. Source0
аддитивная установка совместима со старыми работающими загрузчиками; достаточно
backend/web deployment mutex. Прямой перенос текста обоснования цены в approved
requirements отклонён: классификация и нормализация выполняются следующим срезом.
