# ADR-0116 — ограниченное гибридное обнаружение и восстановление ЕИС

Дата: 2026-10-24. Статус: IMPLEMENTED_LOCAL; production activation pending.
Owner root. Основание: запрос пользователя на автоматическую цепочку и
[контрольные пропуски](../eis/search/128-eis-hybrid-recovery.md).

## Решение

Первый вертикальный срез: tenant local-eis-supplier,44-ФЗ, явный query и предел
страниц1–20. Стартовый профиль «бумага»,3страницы по50. Публичная выдача PRICE↓,
AF и deadlineFrom по дате Москвы, без ограничения публикации. Проверяются echo
всех значимых фильтров, стадия каждой строки, дата и привязка номера к URL.
Неполный разбор учитывается, CAPTCHA/изменённые фильтры не становятся пустой базой.
HTML — discovery evidence, не canonical XML, confirmed-open или участие.

Сохранённые исходные страницы и типизированная tenant/scope очередь связываются
SHA. Отдельное immutable наблюдение имеет собственный SHA, даже при одинаковом
HTML. При обработке очереди страница повторно разбирается. Незавершённая запись
audit повторяется без нового SOAP и не скрывается наличием строки в индексе. Missing номера проходят
существующий S201 recovery/stock number intake целиком; parser не подменяется.
Состояние IN_FLIGHT и задержка повтора сохраняются до сети. Повторный запуск
проверяет базу; successful intake не дублирует редакцию. Ошибки имеют backoff,
истёкший discovery и неподдержанные routes не получают ложный успех.

Один проход:1HTML page,<=3адресных попыток, прежние S201 лимиты сети/архивов,
shared import/priority lease, существующие browser pacing/TLS и joint budget.
Защищённый резерв44/223 сохраняется консервативно. SQL5s, DB<100GiB/free>=40GiB.
State/evidence ограничены2000номеров/256MiB/5000entries. Автоматической очистки
нет: достижение предела останавливает новые проходы; это не бессрочный сервис.
Старые/unsupported записи сохраняются, EXPIRED пока не присваивается автоматически.
XML, версии, отмены, деньги и audit обрабатываются установленными механизмами.

Новый entry point необходим: S201 принимает только NO_DATA-bound S200 report;
он не может принять самостоятельную активную выдачу. Код переиспользует S201
recovery_one/read_indexed и existing source transport; не создаёт второй parser.

## Границы и последствия

Это ограниченный query-driven missing recovery, не national census и не полный
refresh уже имеющихся закупок. PRICE/page pagination меняется при обновлении ЕИС;
обход3страниц не доказывает перечисление всех номеров. Полнота всегда UNKNOWN.
223-ФЗ, автоматический разбор новых XML families, независимые partition counts,
обновления известных номеров и latency поиска — следующие отдельные срезы.
LLM не участвует в скачивании, admission и подсчёте охвата.

Автозапуск допускается после actual-source isolated intake/readback, полного
candidate gate и привязанного production payload по [workflow](../operations/115-candidate-quality-workflow.md).
До активации новый скрипт не запускается с production writes и не добавляется в cron.
Откат — отключение только нового запуска; полученные canonical данные сохраняются.
