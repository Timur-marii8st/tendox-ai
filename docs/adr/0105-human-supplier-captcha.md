# ADR0105: ручная CAPTCHA в серверном браузере

Дата: 2026-10-07. Статус: implemented; прохождение настоящей CAPTCHA человеком pending.

## Контекст

Пользователь разрешил ручное прохождение CAPTCHA. Headed Chrome на VPS не
устранил проверки Google/Яндекса. Runner закрывает браузер за 90 секунд:
ожидание человека требует отдельного lifecycle. Личные cookies не копируются.

## Решение

Оператор открывает ограниченную сессию для точного актуального BLOCKED run.
Это новый процесс Chrome с тем же tenant/origin профилем: ранее закрытая вкладка
не сохраняется. API владеет одной сессией до 10 минут и OS profile lease
до завершения процессов. API проверяет operator/tenant/actor при каждой команде.

UI получает JPEG кадры и отправляет ограниченные click/scroll/text/key.
Публичного CDP/VNC доступа, произвольных URL/JS, downloads и cookie API нет.
Next Server Actions используют аутентификацию защищённого пилота и проверку
Origin; API bearer остаётся на сервере. Ответы no-store/private.
Отдельный request guard разрешает точный запрос и CAPTCHA endpoints/assets;
логин, другая поисковая строка, сторонние карточки и popup запрещены.

Только реальный HTTP/URL/DOM и organic parser с COMPLETED/EMPTY подтверждают
выдачу. HTTP200 и исчезновение CAPTCHA недостаточны. Проверка сохраняет
immutable tenant audit и DOM evidence. Один точный retry получает одноразовый
grant, связанный с tenant/query/engine, expiry и snapshots общего/tenant pacing.
Изменение snapshots отменяет grant. Общие блокировки не удаляются; pacing,
RATE_LIMITED и бюджет поиска сохраняются. Старые результаты неизменяемы.
После подтверждения UI запускает обычное сохранение новой выдачи.

DOM ограничен 8 MiB до передачи из браузера; один общий лимит используют
ручная проверка, обычный transport, parser и web validator. Реальный HTML
Яндекса оказался 2 404 084 bytes: прежние 2 MiB отклоняли настоящую выдачу.
Сжатый SERP bundle по-прежнему ограничен 8 MiB, дневной бюджет — 64 MiB;
превышение остаётся ошибкой, а не неподтверждённым допуском. Ручные admission
ограничены 10/hour и 24/day; отдельный сохранённый DOM — максимум 192 MiB/day.

## Последствия

Проверка или следующий запрос могут снова получить отказ. Отмена/expiry/restart
закрывают процессы; блокировки сохраняются. Только один API worker/хост.
Изготовитель, цена, наличие, технический допуск, КП и PARTICIPATE остаются UNKNOWN.
Реальное прохождение человеком — отдельный live acceptance.

## Альтернативы

noVNC требует отдельного desktop/server/WebSocket доступа. Ограниченные кадры
и команды CDP встраиваются в существующий экран. VPN/прокси — отдельный срез.
