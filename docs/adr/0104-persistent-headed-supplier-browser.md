# ADR0104: постоянный профиль обычного Chrome для серверного поиска

Дата: 2026-10-06. Статус: accepted; установка требует runtime acceptance.

## Решение

В ограниченном supplier SERP срезе обычный Chrome запускается отдельным процессом
с Xvfb и приватным localhost CDP. Playwright читает страницу через CDP; расширение
браузера и Windows UI не нужны. Каждый tenant/origin имеет отдельный профиль,
OS lock и сохранённые паузы. Один VPS и общий защищённый volume — граница поддержки;
несколько хостов потребуют распределённого lease.

Semantic policy v1 сохраняется: запрос, три источника, парсеры, provenance и
значение результата не меняются. Старые результаты читаются source0; транспорт
применяется только к новому явному запуску. Immutable tenant audit сохраняет
transport revision и SHA source/helper, release manifest — image ID и SHA модулей.

Профили не копируются с ноутбука; личные cookies и аккаунты не используются.
Пауза минимум 15 секунд применяется между tenant и глобально на origin;
BLOCKED — один час, RATE_LIMITED — 15 минут, включая рестарт. CAPTCHA прекращает
чтение; новый профиль или смена режима не используются как повторный обход.
Ресурсы ограничены существующими 20/75/90 секундами и DOM 2 MiB.

## Проверенное ограничение

Один обычный headed Chrome с persistent profile на VPS не открыл Google, Яндекс
и Маркет: все показали CAPTCHA. Bing после restart вернул 10 извлекаемых ссылок,
часть нерелевантна. Это подтверждает транспорт и извлечение выдачи, но не выбор
производителя. Роль, цена, наличие, соответствие и КП остаются UNKNOWN.

Контролируемый probe и release evidence находятся в
[контракте SERP](../suppliers/105-eis-position-supplier-serp.md).
Маркет — диагностика границ, а не выпущенный marketplace adapter.

## Установка

Обновление собирается из pinned установленного API image и четырёх модулей;
storage получает только проверенные точечные изменения tenant context/audit.
Незавершённые manufacturer migrations и локальный storage v2 не включаются.
Перед заменой проверяются исходные SHA, staged image ID и исполняемые файлы;
после — installed SHA/import, runtime proof и здоровье API. Есть backup/rollback.
