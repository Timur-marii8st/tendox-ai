# ADR0096 — производные условия из сохранённой товарной карточки

Дата: 2026-10-06. Статус: принято для bounded S226.

## Контекст

S225 получил реальную опубликованную цену. ЕИС требует400пачек; карточка содержит
500листов, упаковку5/100 и технический data-package5. Единица цены/MOQ/шаг
не заявлены. Legacy XML диапазоны неполны; mandatory состав ТЗ не подтверждён.

## Решение

Source0 анализ точного retained PRODUCT HTML с отдельным immutable report.
Парсер ограничен уникальной активной основной карточкой и подтверждённой
разметкой «Бумага-С». Raw поля, packing/contents/order controls разделены,
имеют SHA и locator. Незакрытая или неоднозначная разметка UNKNOWN.

Сохранённый текущий XML и опубликованные поля отображаются рядом. Ограниченный
словарь связывает названия, сохраняет все совпавшие supplier indices; не решает
соответствие и не выдаёт PASS/FAIL. Все коммерческие/технические статусы UNKNOWN.
Когда будет reviewed mandatory requirement contract, используется существующий
domain compliance engine, без нового универсального matching framework.

Report связан с tenant/current позицией, exact PRODUCT request/run/report/body,
parser/mapping revision. Метаданные проверяются до hydration, cache/read безHTML,
prepare идемпотентен. CPU concurrency ограничена. Не дублируются HTML и сеть.

## Последствия

Оператор видит конкретные причины, мешающие сравнению себестоимости. Извлечение
условий не переписывает прежние наблюдения цены. Новая parser revision порождает
новый cache key. Нет предположений MOQ=1, priceperpack или Cэ=C.

## Альтернативы

Умножение опубликованной цены на количество ЕИС может спутать пачку, лист и
коробку. Повторное чтение сайта не нужно для разбора уже сохранённых bytes.
Автоматический admission по публичным legacy характеристикам не подтверждён.
