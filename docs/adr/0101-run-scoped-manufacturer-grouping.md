# ADR-0101: сводка изготовителей одного сохранённого поиска

Дата: 2026-10-06. Статус: принято; локальная реализация проверена.

## Контекст

Независимый review уже связывает юридическое лицо с точной реестровой записью.
Повторный механизм такой связи не нужен. Для выбора изготовителя полезна сводка
всех проверок десяти записей сохранённого ответа. Выбор последнего удобного
решения или объединение похожих названий может скрыть противоречие.

## Решение

- Read-only проекция одного tenant и `run_id`, без сети и новых таблиц.
- Максимум двадцать связанных proposals; двадцать первая запись означает
  `INCOMPLETE / UNKNOWN`. При неполном охвате подтверждённые группы не выдаются.
- Группировать только действующие независимые `identity=PASS` и `role=PASS`
  по точному `(country_code, identifier_scheme, registration_id)`. Регистр,
  пунктуация и похожее название не нормализуются для объединения.
- Несколько юридических идентичностей одной записи или разные юридические
  наименования одного ключа дают `UNKNOWN`. `FAIL` не перекрывается другим
  положительным решением. Просроченный документ источника блокирует запись.
- Сохранять ссылки на каждую product record, proposal, decision и SHA.
  Показывать время оценки и отдельные source/review статусы.
- Общий `PASS` относится только ко всем показанным записям сохранённого ответа;
  он не означает полноту рынка, технический допуск или готовность КП.

## Последствия

Сводка поддерживает выбор доказанного изготовителя, сохраняя противоречащие и
незавершённые проверки. Отдельные товары группы не становятся взаимозаменяемыми.
Связь SKU продавца из S226 с реестровым товаром этим решением не подтверждается.
Контакт, сайт, продавец, техническое соответствие, КП и участие остаются
`UNKNOWN` и требуют собственных evidence и проверок.
