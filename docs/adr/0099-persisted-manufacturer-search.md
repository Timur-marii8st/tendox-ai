# ADR-0099: сохранённый поиск изготовителей по товарным записям ЕАЭС

Дата: 2026-10-06. Статус: принято; локальная реализация проверяется.

## Контекст

Поиск ЕАЭС показывает временную выдачу. Для повторяемой проверки изготовителя
нужны конкретная товарная запись, исходный ответ и адресуемые поля. Товарная
коллекция не содержит стабильного идентификатора юридического лица, пригодного
для автоматического объединения с коллекцией производителей.

## Решение

Сохранять отдельно начало и исход ограниченного поиска в EAEU PRODUCTS.
Начало и audit фиксируются до сети; завершение и audit атомарны. Tenant RLS и
append-only ограничения действуют для всех записей. UUID команды обеспечивает
повтор без сети; изменение запроса для той же команды вызывает конфликт.
Официальный URL фиксирован, запрос формируется сервером. Полностью полученный
ответ до 512 KiB сохраняется даже при ошибке парсера; прерванный ответ не
выдаётся за полный снимок. Не более десяти записей, cooldown и дневной лимит.

Досье строится из проверенного сохранённого ответа по run ID и record ID.
Поля имеют locator и SHA ответа. Производитель — заявление товарной записи;
юридическая идентичность, продавец, бренд, официальный сайт, соответствие и КП
остаются UNKNOWN. Истёкшая дата даёт FAIL; будущая дата не доказывает действительность.
Чтение и выбор кандидата не запускают повторный поиск или внешнее действие.

## Последствия

Можно проверить и повторно открыть происхождение каждого заявления. Сбой
источника отличается от успешной пустой выдачи, незавершённая попытка остаётся
UNKNOWN. Независимый review идентичности и связи с точной моделью нужен отдельно.
Новая выдача не заменяет прежнее evidence и не подтверждает полноту рынка.

## Альтернативы

Объединение компаний по похожему имени, подтверждение изготовителя по бренду
и сохранение данных, присланных браузером, дают неподтверждённую идентичность.
Перезапись последнего ответа лишает проверку воспроизводимости.
