# ADR-0004: полный жизненный цикл с hard gates

Статус: принято 2026-09-05.

## Контекст

Новое ТЗ расширяет продукт от анализа входящего ТЗ до 24/7-мониторинга,
поставщиков, заявок, банковских гарантий, договоров и контроля после победы.
Одновременно требуется рейтинг 0–100 и рекомендация «участвовать».

Если свести юридическую возможность, техническое соответствие, экономику и риск
в один score, высокий средний балл может скрыть фатальный запрет.

## Решение

ProcurementCase становится долгоживущим агрегатом. Решение строится каскадом:
актуальность → legal/company eligibility → compliance → подтверждённое КП →
realistic economics → risk/rating. Score используется только для приоритизации.

Любое внешнее или юридически значимое действие остаётся `A1`: отдельный
ActionRequest, exact-payload hash, ограниченный сроком Approval и receipt от
Local Agent. `A3` не вводится.

## Последствия

- появляются versioned company/legal policies и state machine кейса;
- нужен event/audit log и отдельные analytical projections;
- зелёный рейтинг невозможен как единственное основание участия;
- интеграции вводятся по одной после contract/legal review;
- система может автоматизировать анализ 24/7, не получая права подписи.

## Альтернативы

Один универсальный LLM-агент и единый score отклонены: решение невоспроизводимо,
границы полномочий размыты, `UNKNOWN` и фатальные запреты легко скрыть.
