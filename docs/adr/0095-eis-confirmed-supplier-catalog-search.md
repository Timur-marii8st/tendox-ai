# ADR 0095 — подтверждённый поиск внутри сайта поставщика

Дата: 2026-10-06. Статус: принято для bounded S225.

## Контекст

S224 читает страницу из точной сохранённой поисковой выдачи. Реальные ссылки
по бумаге ведут преимущественно на главные страницы/категории; цены отсутствуют.
Главная «Бумага-С» содержит устойчивую GET форму, а её поиск по полному публичному
наименованию позиции выдаёт товарные ссылки. Доказательства: docs/107.

## Решение

Один адаптер подтверждённой формы. SEARCH выводит query из текущей позиции и
route из retained HTML. PRODUCT выбирает один index 1–10 из exact immutable
SEARCH snapshot. Tenant composite FK, позиция/root/search/report/body SHA и
selected link проверяются при сохранении и чтении. Клиент не передаёт URL.

Каждый этап сохраняет STARTED и final с audit. Только успешное наблюдение источника
может породить следующий этап. CAPTCHA/ошибки с HTML не дают управляемых ссылок.
Read/cache проверяют метаданные до hydration и не загружают HTML.

S224 HTTPS pinned transport ограничен точным hostname на каждом hop. Бюджет и
tenant slot общие с S224. Product microdata — заявление сайта, Decimal и provenance;
скрытые/inert/неоднозначные блоки UNKNOWN. Публичная цена не становится configured
unit cost или полноценным КП.

## Последствия

Появляется проверяемый путь к реальным товарным карточкам без полного crawl.
Первый адаптер покрывает только подтверждённую разметку «Бумага-С». Новый сайт
потребует отдельного evidence и ограниченного adapter. Полное сравнение стоимости
невозможно до проверки упаковки, количества, НДС, доставки и соответствия ТЗ.

## Альтернативы

Обход всех категорий дороже и пока не дал product URLs в retained HTML «Комуса».
Обычный браузер получил robot block. Угаданные URL не имеют provenance. Bing
site-query в диагностике не соблюдал ограничение домена. Эти пути не выбраны.
