# ADR0090: отдельные ценовые наблюдения по позиции ЕИС

Дата: 2026-10-06. Статус: принято, S220 установлен; evidence в docs102.

## Контекст

S219 даёт проверяемый сохранённый текст DOCX, но не закупочную цену. Существующий
Supplier Discovery принимает отдельный uploaded DocumentRecord с утверждённым
типом и extraction PASS. Перенос body-only EIS review в этот контракт подменял
бы непроверенный источник approved requirements. Публичные каталоги публикуют
цены базовых конфигураций, стартовые цены и месячные платежи в разных смыслах.

## Решение

Предварительный read-only discovery начинается от exact current позиции XML;
не требует manual price или признания всего ТЗ полным. Используется один
поддержанный fixed-category adapter. Цена сохраняется отдельным typed fact с
kind/raw label/locator/SHA/time. Она не используется автоматически как Quote,
ServerLead unit cost, налоговая база или источник прибыли.

Сохраняются immutable STARTED и final outcome. Per-search lease и явный refresh
с cooldown ограничивают повторные GET. Сеть выполняется вне транзакций; exact
source/hold/basis проверяется снова перед короткой append транзакцией. Cache
читает последний исход, включая failure/interruption, без сети и bytea hydration.
API prepare выполняется ограниченным дочерним процессом, read — source0.

## Последствия

Получаем связь «позиция ЕИС → найденный товар → конкретный публичный источник».
Рынок, соответствие ТЗ, действительность КП и себестоимость пока UNKNOWN.
Тайм-аут не маскируется старым успехом. Охват одной категории не означает поиск
по всем производителям; расширение требует отдельных адаптеров и source proofs.
Исторический pair reader сохраняет свою семантику без latest gate.

## Альтернативы

Полная локальная копия всех прайсов требует лишнего хранения и всё равно не
подтверждает конфигурацию или условия КП. Генерический «price» парсер создаёт
ложную себестоимость из лизинга/базы. Скрытое преобразование EIS body review в
approved TSpec нарушает границу доказательств. Эти варианты не приняты.
