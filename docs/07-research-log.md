# 07. Реестр фактов — со статусом проверки

Правило из [CLAUDE.md](../CLAUDE.md): непроверенный факт **нельзя** использовать
как основание архитектурного решения.

| Статус | Значение |
|---|---|
| `ПРОВЕРЕНО` | Мы сами открыли первичный источник, дата проверки указана |
| `ТРЕБУЕТ ПРОВЕРКИ` | Взято из внешнего аналитического отчёта, первично не подтверждено |
| `ГИПОТЕЗА` | Наше предположение, требует валидации рынком |

## Важное предупреждение

Исторический блок ниже происходит из предварительного AI-ресёрча, выполненного до старта
проекта. **Его пункты не подтверждены первичным источником.** Новые проверки
датируются отдельно в конце документа.
Отчёт содержал утверждения с датами 2025–2026 гг. и ссылками, которые необходимо
открыть и перепроверить руками, включая: наличие и условия API площадок,
даты запуска ИИ-ассистентов, действующие тарифы конкурентов, рыночные оценки.

Ошибка здесь дорогая: коннектор к несуществующему или платному-по-другому тарифу
API — это выброшенный спринт, а неверная оценка рынка — неверная цена продукта.

Важно: **оборот закупок — не TAM.** Корректный ориентир — рынок закупочного ПО
(SRM/S2P), и он на три порядка меньше. Использовать 65,8 трлн ₽ в презентации
инвестору как TAM — красный флаг.

## Очередь проверки

1. Открыть документацию API B2B-Center, ЕАТ, Bidzaar → зафиксировать реальные
   методы, условия доступа, зависимость от тарифа, позицию по автоматизации.
2. Проверить актуальные тарифы KAPI, Snab.online, Pusk.app → определить ценовой
   коридор.
3. Подтвердить механику подписи CryptoPro на стороне клиента → это основание
   ADR-0001.
4. Подтвердить нормативные требования по КЭП/МЧД у юриста.
5. Найти первичный источник рыночных оценок (Data Insight) и проверить методику.
6. 30–50 интервью с ICP → willingness-to-pay, реальная длительность обработки ТЗ.
7. Получить юридическое заключение по актуальной редакции ПП РФ №1875 и вести
   машиночитаемые перечни как versioned ruleset, а не статические константы.

По каждому подтверждённому пункту статус меняется на `ПРОВЕРЕНО` с датой и прямой
ссылкой на первичный источник.
