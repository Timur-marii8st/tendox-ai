## Маршрут дальнейшей проверки

1. Независимый reviewer проверяет оба DOCX: все 87 строк, дополнительные
   условия основного ТЗ, смысл единиц и обязательность. Только после этого —
   canonical requirements и проверка конкретного товара.
2. По HPE запросить exact BOM: шасси 4LFF, CPU (ядра/частота/потоки/L3),
   4× SATA SSD ≥960 ГБ, 4× DIMM ≥32 ГБ, 2× PSU ≥1300 Вт, контроллер,
   разводка OCP/PCIe/USB, 36-месячный сервис и документы. Запрос не отправлен.
3. [Публичный реестр ГИСП](https://gisp.gov.ru/pp719v2/pub/prod/) проверять
   отдельно по точной модели и реестровой записи, если это нужно условиями
   закупки. При этой проверке прямой доступ к карточкам вернул HTTP 403;
   реестровый статус **UNKNOWN**, его нельзя заменять заявлением производителя.
4. Цена, наличие, сроки, экономика и решение `PARTICIPATE` остаются `UNKNOWN`:
   ни одного действительного КП не получено. Внешних запросов поставщикам,
   отправок и юридических действий не было.

Следующий продуктовый срез — интерфейс/хранилище для независимого подтверждения
кандидатов по точным ячейкам, затем проверка exact BOM и только потом поиск
предложений. Этот отчёт не закрывает обязательный пилот 10–20 комплектов.
