# Единый экран поиска закупок

## Контракт среза

Владелец root; изолированная ветка `codex/tender-search-ui`, база установленного
приложения `f5e1805c0c9ff8895c572dfc020e565059802ff3`. Цель — один запрос
по товару и закону, список закупок и подробности выбранной записи на одном
экране `/tender-discovery`. Данные поступают из действующего API, не из макета.

Owned files: root — `workspace-actions.ts`, проверки server actions и эта
документация и пояснение корзины в `mixed-comparison.tsx`; UI — `workspace.tsx`, `workspace.module.css`, `page.tsx`;
адаптер — `web/src/lib/tender-workspace.ts`, его тесты и конфигурация.
Независимый review проверяет итоговый diff и evidence без правки продукта.
Исходники и передача параллельной задачи загрузки Татарстана не меняются.

## Поведение

- Запрос выполняется для 44-ФЗ, 223-ФЗ или обоих законов. Ошибка одного
  источника не скрывает результат другого и не превращается в ноль совпадений.
- Каждый закон сохраняет собственный снимок, количество и курсор продолжения.
  Это не единый атомарный снимок ЕИС и не общий рейтинг двух законов.
- Поиск не ставит обновление ЕИС в очередь. Существующие операции документов,
  сравнение выбранных закупок с профилем компании и расширенный разбор сохранены.
- Для 44-ФЗ используется существующий режим `NOT_EXPIRED_OR_UNKNOWN`.
  Поиск 223-ФЗ не обещает исключение истёкших сроков; карточка показывает блокер.
- Деньги форматируются из исходных десятичных строк без преобразования в float.
  Цена лота 223-ФЗ не называется НМЦК всей процедуры; несколько лотов не суммируются.
- Наивный или непригодный срок остаётся UNKNOWN. Применимый aware deadline
  отображается в Europe/Moscow. FAIL и запреты действий остаются видимыми.
- Совпадение запроса, схема XML и присутствие карточки не означают соответствие
  ТЗ, открытую подачу, полное КП или рекомендацию PARTICIPATE.
- Область поиска — сохранённая часть ЕИС. Полнота, свежесть и доставка не
  выводятся из региона окна загрузки.

## Явное ограничение

Действующие поисковые DTO не содержат места поставки и не принимают его фильтр.
Поле места поставки недоступно с явным пояснением. Географический фильтр требует
отдельного контрактного среза: адреса/лоты с provenance, неизвестная география,
фильтрация до пагинации, привязка фильтра к курсору и количествам.
Ни интерфейс, ни этот выпуск не подтверждают полный актуальный Татарстан.

## Проверка и выпуск

Acceptance: реальный Next server-action путь, частичный отказ закона, отдельное
продолжение выдачи, сохранение FAIL/UNKNOWN, отсутствие потери точности цены,
клавиатура и мобильная компоновка. Синтетические браузерные данные явно отделены
от production. Секреты не передаются браузеру и не включаются в тестовые ответы.
