# Работа с документацией

Общие правила — в [корневом AGENTS.md](../AGENTS.md). Навигация — в [README.md](README.md).
Текущий порядок и статус хранить только в [live-плане](15-implementation-plan.md).

- Читать тематический README и конкретный контракт; историю искать по заголовку/номеру через rg.
- Различать целевой контракт, выпущенный механизм и подтверждённый production результат.
- Подробные acceptance, source/SHA и результаты проверок хранить в тематическом отчёте.
- Исторические журналы помещать в history; ADR сохранять с исходным номером и решением.
- Новый файл индексировать в README своей папки; при переносе исправлять входящие и исходящие ссылки.
- После изменения запускать `uv run python scripts/check_docs.py`.
- Live-план ограничен 120 строками; общий README — 100 строками, корневой — 120.

- Бюджеты символов входных файлов заданы в `scripts/check_docs.py`; длинные строки не обходят лимит.
