## Источники истины

- PRD задаёт требования, архитектура и ADR — контракты и решения.
- Live-план задаёт текущий порядок; тематический отчёт содержит evidence конкретного выпуска.
- Код и проверки подтверждают реализацию только в проверенных границах.
- Исторические NEXT, размеры БД, результаты тестов и старые статусы не являются live-данными.
- При расхождении не выбирать удобный PASS: уточнить контракт и записать решение.

## Поддержание структуры

Новый материал помещать в тематическую папку; добавлять ссылку в её README.
Общие инструкции хранить в корневом AGENTS/CLAUDE, локальные — в AGENTS области.
Не дублировать инварианты и live-статус во всех индексах. Существующие числовые
идентификаторы документов и ADR сохранены; исторические номера не перенумеровывать.
В ADR при переносе изменены только локальные пути ссылок, текст решений сохранён.

Проверка ссылок, индексов и размеров входных файлов:
`uv run python scripts/check_docs.py` (также выполняется отдельным CI job).
